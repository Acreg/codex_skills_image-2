GPT-image2 图片生成工具 v4.2.0

项目：https://github.com/Acreg/codex_skills_image-2

完整解压 ZIP 后：
- Windows：双击根目录“安装图片Skill.cmd”；如缺少 Python 或 Pillow，按提示决定是否安装。
- macOS/Linux：运行 sh image-image-generation-portable/install-codex.sh（需 Python 3.11+）。
- 其他客户端：python image-image-generation-portable/install.py --skills-dir <客户端技能目录>。

所有安装文件使用相对路径。已有 .env 和独立配置会保留；首次安装会创建 .env 模板。Codex API 登录使用当前 Onemini provider；Codex 非 API 登录使用内置生图；其他客户端将 Key 填入 .env 的 OPENAI_API_KEY。Gemini 到 api.onemini.top 新建 gemini-cli 渠道分组 Key，填入 GEMINI_API_KEY。不要公开 Key。

默认 gpt-image-2.6；GIF 使用 --output-format gif，不传分辨率。结果默认保存当前聊天工作区 output/imagegen/ 并显示在聊天。若无 Pillow，先询问用户；同意后运行当前 Python 的 pip install Pillow。包内 Windows Python 安装程序和对应离线 wheel 只适用于 Windows x64。
