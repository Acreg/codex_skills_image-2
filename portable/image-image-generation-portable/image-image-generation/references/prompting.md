# 提示词与固定测试内容

仅在需求模糊、文字密集、编辑约束复杂或用户要求模型测试时读取。

## 快速整理规则

- 用户提示已经具体：保持原意，仅整理为一段，不扩写成方案。
- 普通短提示：最多补充主体清晰、构图、光线和成品风格；不自行增加日期、品牌或长文案。
- 精确文字：用引号给出原文，注明位置和“不得出现其他文字”。
- 图生图：明确“只改变什么”和“保持什么”，每轮只处理用户当前修改。
- 用户只说“生图测试”：使用 `--preset benchmark-t2i`，不要临时设计新测试。

## benchmark-t2i 固定提示词

脚本内置以下稳定测试，便于跨模型比较：

```text
横版电影级科幻摄影：黄昏的红色峡谷太阳观测站，中央金色环形日冕装置产生清晰放射光，前景三名穿白色科研服的人物，左侧全息太阳图，右侧机械臂与反射镜阵列，明确前中后景、真实光影和精密材质。画面仅出现三行清晰英文：PROJECT SUNBURST；LIGHT, MEASURED.；09 SEPTEMBER 2026。无水印、无额外文字、人物结构自然，成品级。
```
