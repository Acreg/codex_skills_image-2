# 生图监测与异常处理

## 请求模型显示

- 发送开始提示前先解析本次请求模型：用户显式模型 > preset 模型 > 默认模型 `gpt-image-2.5-flare`。
- 开始提示固定为：

  ```text
  图片生成请求已发送，使用模型{MODEL_ID}正在绘图中，请稍后
  ```

- `{MODEL_ID}` 使用请求提交时确定的模型 ID。此处不等待、不猜测响应模型，也不把其他任务的模型带入本次报告。

## 30 秒固定监测

- 请求提交后从 0 秒开始计时，在 30、60、90 秒等时间点固定检查并播报一次；状态不变也必须播报。
- 进度播报固定为：

  ```text
  图片生成进度：使用模型{MODEL_ID}，已等待{SECONDS}秒，当前状态：{OBSERVED_STATUS}
  ```

- 状态来源只能是本次精确 image generation call、正在运行的进程或对应会话记录。
- 没有真实百分比或阶段事件时使用“等待上游响应”“已提交，等待结果”等可验证状态；不得虚构百分比、阶段或预计剩余时间。
- 如果调用在第一个 30 秒节点前完成，不额外制造进度播报；完成、明确失败、被动断开或调用结束后立即停止后续播报。
- 智能体不得因等待时间变长主动取消、断开、终止、制造超时或放弃请求。

## 错误处理

发生实际错误时立即停止 30 秒监测，并按 [errors.md](errors.md) 输出错误码/类别、脱敏原始报错、中文翻译和解决建议。不得自动重试、切换模型、改写提示词或把未知结果说成成功。

## 风控

遇到“您的请求无法用于生图，因为……”等拒绝，立即原样转告上游返回内容，然后发送：

```text
请根据上述原因调整提示词后重新提交。请勿生成低俗色情、血腥暴力、证件造假、诈骗等内容；此类内容可能触发风控，并可能导致管理员封禁账号。
```

停止本次等待，不自动改写提示词、绕过风控或重试。

## HTTP 错误

立即报告实际错误码和原始信息。502 通常表示网关收到无效上游响应或上游连接异常；503 通常表示服务暂时不可用、过载、维护或暂无可用上游。其他错误不得猜测根因，也不得把失败说成成功。

## Cloudflare 被动断开

实际被动断开后告知：

```text
本次生图请求提交后超过 2 分钟仍未收到回复，连接已被 Cloudflare 断开。这个限制无法通过 Skill 绕过，也不是站长刻意设置的；生图耗时较长时，普通网页请求可能遇到该断开问题。

如果多次出现，请改用 https://api.onemini.top 侧边栏的“图片生成工作站”进行生图，以免普通网页请求受到该连接限制。
```

断开后先尝试从本次精确调用恢复并交付；恢复不到时才等待用户重新提交。不得预先把等待 2 分钟判为断开。
