# codex_skills_image-2
[codex]image-2图片生成skills

让你的codex在使用中转的时候依然可以使用image-2模型生成图片

第一步
下载压缩包
https://github.com/Acreg/codex_skills_image-2/releases

第二步
把安装包拖动到codex让他安装
<img width="1244" height="319" alt="image" src="https://github.com/user-attachments/assets/4153af14-52af-4a1c-807a-0adcc8e90cbb" />

第三步
对话框输入“/”打开技能选择界面
找到"image-2图片生成"，选择后让codex使用这个技能来生成图片即可

<img width="1253" height="413" alt="image" src="https://github.com/user-attachments/assets/d22c2969-50cd-46f5-a354-8599474a8eae" />
